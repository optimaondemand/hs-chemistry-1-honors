# Chemistry I Honors — Interactive Lessons (Semester 1)

Interactive lesson pages for **Chemistry I Honors** (Florida CPALMS #2003350), Optima Academy Online.
These pages are hosted via GitHub Pages and embedded into the Canvas course by `<iframe>`.

- `module-00/` … `module-04/` — Semester 1 lesson pages (widgets run on the hosted page).
- `semester-1-review-exam/semester-1-review.html` — Semester 1 cumulative review page.

Graded items (quizzes, assignments, VR/hands-on) are built natively in Canvas, not here.
